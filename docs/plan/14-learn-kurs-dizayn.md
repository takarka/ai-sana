## Что на макетах

| # | Экран | Маршрут |
|---|---|---|
| 1 | Карта курса (полная) | `/matrix` |
| 2 | Курс не подключён | `/matrix` (пустое) |
| 3 | Урок: материалы + задания | `/matrix/lessons/:id` |
| 4 | Задание — ответ (одиночный выбор) | `/matrix/lessons/:id/tasks/:taskId` |
| 5 | Задание — результат без правильного ответа | тот же |
| 6 | Задание — пересдача | тот же |
| 7 | Задание — попытки исчерпаны | тот же |
| 8 | Другой тип в том же каркасе (соответствие) | тот же |
| 9 | Урок на телефоне | `/matrix/lessons/:id` |

## Правила UI (из планов)

- Урок открыт целиком, задания в любом порядке — нет пошагового плеера.
- Статус = текст + значок + цвет (NFR-A11Y-03).
- После сдачи: балл `%` и что не зачтено; **правильный ответ не показываем** (Р-1).
- Лимит попыток виден до ответа; по умолчанию лимита нет.
- «Назад» = вверх по структуре: задание → урок → раздел/курс.

## Вне объёма

PISA, BUILDER, живая сессия урока, симуляторы, журнал учителя, методичка —
отдельные макеты или вёрстка по своим планам.
