# Дизайн — навигация и главные страницы (`apps/learn`)

**Статичные макеты учебной оболочки**, до вёрстки `apps/learn`. Закрывают
объём [плана 12](12-learn-navigatsiya-i-glavnaya.md): главные ученика и
учителя, переключение модулей, «продолжить», адаптив и junior — **без**
углубления в экраны урока, заданий MATRIX/PISA и BUILDER.

**Схема в HTML.** [13-learn-navigatsiya-dizayn.html](13-learn-navigatsiya-dizayn.html)
— открывается в браузере без сборки (шрифты с Google Fonts).

[03-design-system.md](03-design-system.md) — токены и модульные акценты.
[12-learn-navigatsiya-i-glavnaya.md](12-learn-navigatsiya-i-glavnaya.md) —

## Чем это не админка

| | `apps/admin` (план 10) | `apps/learn` (этот макет) |
|---|---|---|
| Каркас | Сайдбар + таблицы | Верхние вкладки / нижняя панель |
| После входа | Обзор платформы | «Продолжить» + модули |
| Навигация | Разделы администрирования | Модули обучения (ученик) / классы (учитель) |
| Плотность | `compact`, много строк | `comfortable` / `junior`, воздух вокруг действия |
| Общее | Токены цвета и шрифтов | Те же токены, другая подача |

## Что на макетах

1. **Главная ученика** (`/`) — строка «кто я», карточка «Продолжить», две
   карточки модулей, последние результаты.
2. **Курс** (`/matrix`) — лёгкая карта разделов (только чтобы показать, куда
   ведёт вкладка; без плеера и заданий).
3. **Тренажёры** (`/pisa`) — выбор направления (вход в модуль, без стимула).
4. **Урок — только оболочка** — шапка, «← уровень выше», заглушка контента.
   Детали MATRIX вне этого файла.
5. **Главная учителя** (`/teach`) — «требует внимания» + мои классы + селектор
   класса в шапке.
6. **Телефон &lt;640** — нижняя панель Главная · Курс · Тренажёры.
7. **Junior 1–4** — одна карточка «Продолжить» и крупный список уроков, без
   вкладок PISA.

## Проверено при сборке макета

- Цвета `--brand`, `--m-matrix`, `--m-pisa`, `--paper`, `--on-paper` совпадают
  с `libs/shared/ui-tokens`.
- Активная вкладка и кнопка «Продолжить» берут цвет модуля / бренда по правилам
  плана 12 §7.
- База кадра десктопа — **1366×768** (Н-7).

## Вне объёма

Типы заданий, стимул PISA, методичка, таблица результатов класса, BUILDER —
следующими макетами или сразу вёрсткой по планам 06/07/11.
