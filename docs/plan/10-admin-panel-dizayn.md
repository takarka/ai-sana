# Дизайн — логин и админ-панель (`apps/admin`)

**Статичные макеты для согласования визуала**, до начала вёрстки экранов
`apps/admin`. Покрывают три экрана из [09-admin-panel-razrabotka.md](09-admin-panel-razrabotka.md):
вход, общий layout кабинета (сайдбар/топбар) и «Школы и организации» (список
+ панель школы с классами + модалка создания школы).

**Схема в HTML.** [10-admin-panel-dizayn.html](10-admin-panel-dizayn.html) —
статичный снимок всех четырёх экранов, открывается прямо в репозитории без
внешних зависимостей (кроме шрифтов с Google Fonts). Интерактивная версия (с
возможностью правки в браузере) —
[claude.ai/code/artifact/7cc7ff34-3c73-4a2a-b403-dc9e9a13c8b8](https://claude.ai/code/artifact/7cc7ff34-3c73-4a2a-b403-dc9e9a13c8b8);
доступ к ней приватный (аккаунт Anarbek), `.html`-файл в репозитории — это
то, на что может опираться любой участник команды без доступа к аккаунту.

**Смежные документы.**
[03-design-system.md](03-design-system.md) — источник всех токенов, шрифтов,
плотности и правил (заголовки без 800 UPPER, статус = цвет+иконка+текст),
использованных в макетах без единого произвольного значения.
[09-admin-panel-razrabotka.md](09-admin-panel-razrabotka.md) — бэкенд
(`/platform/orgs`, `/auth/login`), под который сверстаны данные на макетах.
[ADR-0005](../adr/0005-razdelenie-kabineta-na-admin-i-learn.md) — почему это
`apps/admin`, а не общий `craft-web`.

## Что на макетах

1. **Вход** — email/пароль, JWT (план 09, A1). Карточка на `--paper`, без
   тёмной сцены (§3.2 плана 03: ink — только дашборд учителя и проекция).
2. **Layout кабинета** — сайдбар (Обзор · Школы и классы · Разделы и уроки ·
   PISA-задания) + топбар (поиск, уведомления, профиль). Контент справа —
   дашборд «Обзор» как экран по умолчанию после входа.
3. **Школы и организации** — таблица школ + панель выбранной школы (учебный
   год, классы `A2.3`, последний импорт `A2.5-8`). Кнопка «Создать школу»
   открывает модалку.
4. **Модалка «Создать школу»** — название + регион; учебный год создаётся
   автоматически на бэкенде (`CreateOrganization`, план 09 §A2.2).

## Проверено при согласовании

Макеты прогнаны сверкой с реальными токенами `libs/shared/ui-tokens` и
компонентами `libs/shared/ui` (button, status-badge, data-table): цвета,
радиусы, шрифты и веса совпадают буквально; один найденный дефект —
контраст KPI-дельт на дашборде («+6 за месяц» зелёным текстом на белом,
~3.4:1 — тот же баг, что уже был исправлен в `status-badge`, §6 плана 03) —
исправлен: текст нейтральный `--fg-dim`, цвет уровня несёт только иконка.

## Открытые вопросы для вёрстки

- Данные на экранах (школы, ФИО, числа) — примерные для показа плотности
  таблицы и панели, не тянуть в код как есть.
- Плотность выбрана `comfortable`; переключатель `compact`/`junior` на
  экране 3 показан как заготовка на будущее, логика переключения не в
  объёме этого макета.
- Классы школы показаны как плоская сетка чипов — если в `A2.3` появится
  постраничность или сортировка по параллели, это меняет только панель
  школы, не остальные три экрана.
