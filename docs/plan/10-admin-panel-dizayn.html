Что учесть при вёрстке

  • Заголовки экранов — Inter Tight 600, без капса: 800 UPPER остаётся только за крупными числами дашборда и короткими метками (§3.3 плана 03).
  • Статус всегда кодируется цветом + иконкой + текстом; текст статуса — нейтральный --fg, цвет уровня несёт только иконка (тот же контракт, что у status-badge, §6 плана 03) — на макете «Обзор» это уже применено к дельтам KPI.
  • Плотность таблицы — comfortable (--row-h: 5.6rem); переключатель на макете «Школы и организации» показывает, что compact/junior тоже предусмотрены на будущее.
  • Данные на всех экранах — примерные (школы, ФИО, числа), для реальной вёрстки брать из API /platform/orgs.
  • Интерактивный канвас (с возможностью правки в браузере) — claude.ai/code/artifact/7cc7ff34-3c73-4a2a-b403-dc9e9a13c8b8; этот файл — статичный снимок для истории и офлайн-просмотра в репозитории.
