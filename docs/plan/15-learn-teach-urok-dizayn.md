# Дизайн — урок для учителя (`apps/learn` · контур teach)

**Задача.** Экран урока ученика ([14](14-learn-kurs-dizayn.md)) нельзя
копировать учителю: у него другие цели. Этот документ фиксирует разницу и
даёт макеты.

## 1. В чём была дыра

| Что нужно учителю | Что давали старые планы | Почему плохо |
|---|---|---|
| Оценить качество и сложность задания до урока | Р-3 плана 11: «предпросмотра глазами ученика нет» | Учитель либо гадает, либо логинится учеником |
| Увидеть ответы / эталон | У ученика эталон скрыт (Р-1) — справедливо | Учителю эталон нужен, иначе «проверить» бессмысленно |
| Методические материалы | Отдельный `/method-card` | Отрывается от урока; часть материалов «только учитель» негде показать рядом с заданиями |
| Результаты класса | Отдельная таблица `.../results` | Ок, но вход к ней должен быть с того же урока, не «другой мир» |
| Не портить журнал своими попытками | Не описано | Если учитель жмёт «Сдать» как ученик — пишет попытку не туда |

**Вывод.** Учителю нужен **режим подготовки**, а не режим сдачи и не клон
ученического UI.

---

## 2. Две аудитории — два контракта на один урок

Один и тот же `lessonId`, разный API и разный UI.

| | Ученик `/matrix/lessons/:id` | Учитель `/teach/classes/:classId/lessons/:id` |
|---|---|---|
| Материалы | Только `visibility=student` | Все: student + **teacher-only** (бейдж) |
| Методичка / план | Нет | Блок в подготовке (бывший method-card) |
| Задания | «Сдать» → балл в прогресс | «Проверить» → эталон, **без** записи в прогресс класса |
| Эталон ответа | Скрыт (Р-1) | Показывается после «Проверить» или по кнопке «Показать эталон» |
| Результаты | Свои | Таблица класса: первая / лучшая / попытки |
| Главный CTA | Сдать / продолжить | Результаты класса · проверить задание |

Сервер отдаёт teacher-only материалы только ролям `teacher`/`homeroom` (и
выше по политике). Ученику они **не приходят** в JSON — не «скрыты CSS».

## 3. Маршруты (уточнение)

| Маршрут | Экран |
|---|---|
| `/teach/classes/:classId` | Курс класса: уроки + агрегаты (как T-2) |
| `/teach/classes/:classId/lessons/:lessonId` | **Урок учителя:** вкладки Подготовка \| Результаты |
| `/teach/classes/:classId/lessons/:lessonId/tasks/:taskId` | Проверка задания (песочница учителя) |
| `/teach/classes/:classId/lessons/:lessonId/results` | Редирект/якорь на вкладку «Результаты» |
| `/teach/lessons/:lessonId/method-card` | Редирект на подготовку урока (якорь `#method`) — URL из старых закладок не ломаем |

Контекст класса в пути обязателен: у учителя несколько классов, селектор в
шапке переключает `classId`, оставаясь на том же уроке, если урок общий.

---

## 4. Что на макетах

1. Курс класса — строка урока ведёт в урок учителя, не в ученический `/matrix`.
2. Урок · вкладка «Подготовка» — teacher-only материалы, методичка, задания с
   действием «Проверить».
3. Урок · вкладка «Результаты» — сводка по заданиям + таблица учеников.
4. Песочница задания — «Проверить», эталон, пометка «не влияет на журнал».
5. Сравнение крошечным блоком: что видит ученик vs учитель на одних материалах.

---

## 5. Решение вместо Р-3

**Было (Р-3):** учителю нет предпросмотра «глазами ученика»; это только у
методиста в `apps/admin`.

**Стало:** у учителя есть **режим подготовки** — пройти задание, увидеть
эталон, оценить сложность. Это не «логин учеником» и не запись попытки в
класс. Методист в admin по-прежнему правит контент; учитель контент не
редактирует.
