## Что это за система (кратко)

CRAFT AI — учебная платформа (LMS + симуляторы + ИИ-контур) из трёх модулей:

- **CRAFT MATRIX** — цифровой комплекс для предмета «Цифровая грамотность и ИИ»,
  1–11 классы, привязан к целям обучения ГОСО/ТУП, с автопроверкой и дашбордом учителя.
- **CRAFT BUILDER** — внеурочный практический курс ИИ-инженерии: промпт-инжиниринг,
  вайб-кодинг, автономные агенты, портфолио проектов ученика.
- **CRAFT PISA** — тренажёры функциональной грамотности и диагностика готовности
  школы к PISA-2029, включая спецмодуль медиа- и ИИ-грамотности.
