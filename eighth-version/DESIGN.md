# CRAFT AI — Брендбук и дизайн-система (eighth-version)

Единая образовательная операционная система для школ Республики Казахстан:
**CRAFT MATRIX** · **CRAFT BUILDER** · **CRAFT PISA**

---

## 1. Позиционирование и аудитория

- **Продукт:** CRAFT AI — комплексное решение для интеграции искусственного интеллекта и системной подготовки к исследованиям PISA-2029 в казахстанских школах.
- **Целевая аудитория:** Директора школ, завучи, руководители Управлений образования (УоО), учителя информатики и цифровой грамотности.
- **Ключевой месседж:** «Учитель не лектор, а тьютор. Система учит, учитель адресно помогает тем, кто буксует».

---

## 2. Цветовая система и брендовый слой

Архитектура сайта построена на чередовании полос `.band--ink` (тёмная сцена) и `.band--paper` (светлая рабочая среда). Каждый модуль экосистемы имеет собственный семантический акцент, проверенный на соответствие стандарту **WCAG 2.1 AA** (контраст ≥ 4.5:1 для основного текста).

### Палитра ядра и модулей

Контраст посчитан по формуле WCAG 2.1 (относительная яркость sRGB) — `--signal` на белом (`--card`/`--paper`), `--signal-lift` на `--ink-900` (`#04060F`).

| Модуль | Класс страницы | Светлый акцент (`--signal`) | Тёмный акцент (`--signal-lift`) | Контраст на белом | Контраст на `--ink-900` |
|---|---|---|---|---|---|
| **CRAFT AI (Ядро)** | `.page--home` | `#0004EB` | `#7E8BFF` | 9.5:1 | 6.8:1 |
| **CRAFT MATRIX** | `.page--matrix` | `#0047BA` | `#58B2FF` | 8.0:1 | 8.9:1 |
| **CRAFT BUILDER** | `.page--builder` | `#5B16D0` | `#A78BFA` | 8.5:1 | 7.4:1 |
| **CRAFT PISA** | `.page--pisa` | `#006C59` | `#2DD4BF` | 6.4:1 | 10.9:1 |

Все восемь значений ≥ 4.5:1 — требование WCAG AA для основного текста выполняется с запасом.

### Семантическая шкала статусов учеников (Дашборд)

Дашборд (`#desk`) лежит на `band--ink`, поэтому у шкалы статусов есть **две версии токенов**:
- `--lvl-high/-mid/-low` — приглушённые тона для paper-полос (`.lz__verdict`, `.hard` на CRAFT PISA).
- `--lvl-high-ink/-mid-ink/-low-ink` — та же семантика, но ярче, для текста и заливок на тёмном фоне.

| Статус | Токен (ink) | Цвет | Контраст на `--ink-900` |
|---|---|---|---|
| Зелёный (`.desk-badge--green`) | `--lvl-high-ink` | `#2ED573` | 10.5:1 |
| Жёлтый (`.desk-badge--yellow`) | `--lvl-mid-ink` | `#FFA502` | 10.2:1 |
| Красный (`.desk-badge--red`) | `--lvl-low-ink` | `#FF4757` | 6.1:1 |

*Важно:* статус кодируется не только цветом, но и обязательным текстом с иконкой (`.desk-badge::before` + подпись), что обеспечивает полную доступность и для дальтоников, и для скринридеров.

## 3. Типографика

Используется система трёх голосов, поддерживающая расширенную кириллицу (казахские глифы Ә, Ғ, Қ, Ң, Ө, Ұ, Ү, Һ, І):
1. **Display (Inter Tight 800 UPPER):** Мощный инженерный тон для H1 и H2. Использование отрицательного letter-spacing (`-.02em`) и line-height (`.94`).
2. **Body (Onest 400/500/600):** Нейтральный, легко читаемый гротеск для описаний, методических параграфов и таблиц.
3. **Micro / UI (JetBrains Mono 500/600):** Моноширинные метки, статусы, тайминги, кнопки, чипсы и код.

## 4. Навигация

Шапка на всех 4 страницах содержит ровно 4 пункта меню — без якорных ссылок на секции и без выпадающих подменю:

`[Экосистема] [CRAFT MATRIX] [CRAFT BUILDER] [CRAFT PISA]`

`Экосистема` ведёт на `index.html`, остальные три — на соответствующую страницу модуля; активная страница помечается классом `.is-active`. Бургер-меню на мобильных схлопывает эти же 4 пункта, порог — `max-width: 1180px` (при более узкой навигации с длинными русскими и казахскими подписями шапка переполняется на `builder.html`/`pisa.html`).

## 5. Моторика и деградация

- **GSAP + ScrollTrigger** подключены (`async`, с CDN) только на `matrix.html` — это единственная страница со скролл-сценарием (`initHowScrub`). На остальных трёх `window.gsap` не определён, лишние ~90 КБ не загружаются.
- **Lenis** из проекта убран полностью — плавный скролл не использовался ни в одном инициализаторе.
- `CRAFT.whenGsap(cb)` в `core.js` — опрос с таймаутом 3 c на случай недоступности CDN; без GSAP скролл-скраб просто не активируется, сайт остаётся рабочим.
- `prefers-reduced-motion: reduce` замораживает ревилы и уничтожает WebGL-сцену (`freezeMotion()`).
- `<noscript>` в `<head>` каждой страницы принудительно показывает `.js-rise`/`.js-fade`/`.word` и скрывает прелоадер — без JS контент не остаётся невидимым (обычно эти классы стартуют с `opacity: 0` и раскрываются `IntersectionObserver`'ом).

## 6. Доступность модалки заявки

Модалка (`#modal`, `role="dialog"`, `aria-modal="true"`) в `core.js`:
- запоминает элемент, с которого была открыта, и возвращает на него фокус при закрытии;
- ставит `aria-hidden` + `inert` на `header/main/footer`, пока открыта;
- блокирует скролл `body` (`position: fixed` с сохранением `scrollY`);
- держит фокус внутри модалки по `Tab`/`Shift+Tab` (циклический focus trap);
- закрывается по `Escape` и по клику на фон/крестик.

## 7. Архитектура проекта

Бессборочная модульная структура (Pure HTML5 + Vanilla CSS + Modular JS):

```
eighth-version/
├── index.html              # Главная экосистемы (5 блоков ТЗ + Дашборд + Эксперты + FAQ)
├── matrix.html             # CRAFT MATRIX (3 блока: Hero, Сценарий урока, ГОСО/ТУП)
├── builder.html            # CRAFT BUILDER (4 блока: Hero, Подход, Программа 4 шага, Результаты)
├── pisa.html               # CRAFT PISA (3 блока: Hero, 3 уровня подготовки, Управленческий дашборд)
├── styles.css              # Общая дизайн-система с модульными темами
├── scene.js                # WebGL Three.js сцена с параметризацией цвета
├── DESIGN.md               # Данная спецификация
└── js/
    ├── i18n.js             # Ядро локализации с динамической регистрацией словарей
    ├── core.js             # Общая UI-логика (прелоадер, шапка, бургер, модалка, boot сцены)
    ├── page-home.js        # Дашборд со статусами учеников, фильтрация, FAQ, пины героя
    ├── page-matrix.js      # Скраб-сценарий урока
    ├── page-builder.js     # Интерактивный тренажёр промптов
    ├── page-pisa.js        # Рукописные SVG-графики динамики готовности
    └── lang/
        ├── common.js       # Общие переводы (навигация, модалка, футер)
        ├── home.js         # Словарь главной страницы (RU + KZ)
        ├── matrix.js       # Словарь CRAFT MATRIX (RU + KZ)
        ├── builder.js      # Словарь CRAFT BUILDER (RU + KZ)
        └── pisa.js         # Словарь CRAFT PISA (RU + KZ)
```

## 8. Что изменено по сравнению с `seventh-version`

1. **Репозиционирование:** Вместо каталога 14 разрозненных детских курсов представлено 3 комплексных институциональных модуля.
2. **Аудитория:** Тексты и интерфейсы ориентированы на лиц, принимающих решения в школах (директора, завучи, УоО).
3. **Навигация:** 8+ пунктов меню и якорные ссылки на секции заменены на 4 постоянных пункта — по одному на экосистему и каждый модуль.
4. **Дашборд:** Добавлен наглядный интерфейс контроля класса в реальном времени со статусами зелёный/жёлтый/красный.
5. **Эксперты:** Добавлен блок 4 ключевых экспертов с государственными регалиями РК и академическим весом.
6. **Нормативная база:** Добавлены акценты на ИМП 2026–2027, критерии F/P для 2–4 классов и законодательство РК по защите данных.
7. **WebGL Сцена:** Захардкоженные цвета вынесены в параметры и динамически считываются из CSS текущей страницы модуля.
8. **Моторика:** Lenis убран полностью, GSAP/ScrollTrigger оставлены только на `matrix.html` — на остальных трёх страницах анимации ограничены CSS-ревилами.
