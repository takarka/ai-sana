# CRAFT AI — Брендбук и дизайн-система (eighth-version)

Единая образовательная операционная система для школ Республики Казахстан:
**CRAFT MATRIX** · **CRAFT BUILDER** · **CRAFT PISA**

---

## 1. Позиционирование и аудитория

- **Продукт:** CRAFT AI — комплексное решение для интеграции искусственного интеллекта и системной подготовки к исследованиям PISA-2029 в казахстанских школах.
- **Целевая аудитория:** Директора школ, завучи, руководители Управлений образования (УоО), учителя информатики и цифровой грамотности.
- **Ключевой месседж:** «Учитель не лектор, а тьютор. Система учит, учитель адресно помогает тем, кто буксует».

---

## 2. Цветовая система и брендовый слой

Архитектура сайта построена на чередовании полос `.band--ink` (тёмная сцена) и `.band--paper` (светлая рабочая среда). Каждый модуль экосистемы имеет собственный семантический акцент, проверенный на соответствие стандарту **WCAG 2.1 AA** (контраст ≥ 4.5:1 для основного текста).

### Палитра ядра и модулей

| Модуль | Класс страницы | Светлый акцент (`--signal`) | Тёмный акцент (`--signal-lift`) | Контраст на белом | Контраст на `--ink-900` |
|---|---|---|---|---|---|
| **CRAFT AI (Ядро)** | `.page--home` | `#0004EB` | `#7E8BFF` | 8.6:1 | 8.5:1 |
| **CRAFT MATRIX** | `.page--matrix` | `#0047BA` | `#58B2FF` | 6.5:1 | 9.8:1 |
| **CRAFT BUILDER** | `.page--builder` | `#5B16D0` | `#A78BFA` | 7.2:1 | 8.9:1 |
| **CRAFT PISA** | `.page--pisa` | `#006C59` | `#2DD4BF` | 5.2:1 | 10.4:1 |

### Семантическая шкала статусов учеников (Дашборд)
- **Зеленый статус (`.desk-badge--green`):** `#2ED573` (В темпе / Опережает график).
- **Желтый статус (`.desk-badge--yellow`):** `#FFA502` (Замедление / Требует внимания).
- **Красный статус (`.desk-badge--red`):** `#FF4757` (Нужна помощь / Ошибки в симуляторе).
*Важно:* Статус кодируется не только цветом, но и обязательным текстом с иконкой, что обеспечивает полную доступность.

## 3. Типографика

Используется система трёх голосов, поддерживающая расширенную кириллицу (казахские глифы Ә, Ғ, Қ, Ң, Ө, Ұ, Ү, Һ, І):
1. **Display (Inter Tight 800 UPPER):** Мощный инженерный тон для H1 и H2. Использование отрицательного letter-spacing (`-.02em`) и line-height (`.94`).
2. **Body (Onest 400/500/600):** Нейтральный, легко читаемый гротеск для описаний, методических параграфов и таблиц.
3. **Micro / UI (JetBrains Mono 500/600):** Моноширинные метки, статусы, тайминги, кнопки, чипсы и код.

## 4. Архитектура проекта

Бессборочная модульная структура (Pure HTML5 + Vanilla CSS + Modular JS):

```
eighth-version/
├── index.html              # Главная экосистемы (5 блоков ТЗ + Дашборд + Эксперты + FAQ)
├── matrix.html             # CRAFT MATRIX (3 блока: Hero, Сценарий урока, ГОСО/ТУП)
├── builder.html            # CRAFT BUILDER (4 блока: Hero, Подход, Программа 4 шага, Результаты)
├── pisa.html               # CRAFT PISA (3 блока: Hero, 3 уровня подготовки, Управленческий дашборд)
├── styles.css              # Общая дизайн-система с модульными темами
├── scene.js                # WebGL Three.js сцена с параметризацией цвета
├── DESIGN.md               # Данная спецификация
└── js/
    ├── i18n.js             # Ядро локализации с динамической регистрацией словарей
    ├── core.js             # Общая UI-логика (прелоадер, шапка, бургер, модалка, boot сцены)
    ├── page-home.js        # Дашборд со статусами учеников, фильтрация, FAQ, пины героя
    ├── page-matrix.js      # Скраб-сценарий урока
    ├── page-builder.js     # Интерактивный тренажёр промптов
    ├── page-pisa.js        # Рукописные SVG-графики динамики готовности
    └── lang/
        ├── common.js       # Общие переводы (навигация, модалка, футер)
        ├── home.js         # Словарь главной страницы (RU + KZ)
        ├── matrix.js       # Словарь CRAFT MATRIX (RU + KZ)
        ├── builder.js      # Словарь CRAFT BUILDER (RU + KZ)
        └── pisa.js         # Словарь CRAFT PISA (RU + KZ)
```

## 5. Что изменено по сравнению с `seventh-version`

1. **Репозиционирование:** Вместо каталога 14 разрозненных детских курсов представлено 3 комплексных институциональных модуля.
2. **Аудитория:** Тексты и интерфейсы ориентированы на лиц, принимающих решения в школах (директора, завучи, УоО).
3. **Дашборд:** Добавлен наглядный интерфейс контроля класса в реальном времени со статусами зелёный/жёлтый/красный.
4. **Эксперты:** Добавлен блок 4 ключевых экспертов с государственными регалиями РК и академическим весом.
5. **Нормативная база:** Добавлены акценты на ИМП 2026–2027, критерии F/P для 2–4 классов и законодательство РК по защите данных.
6. **WebGL Сцена:** Захардкоженные цвета вынесены в параметры и динамически считываются из CSS текущей страницы модуля.
