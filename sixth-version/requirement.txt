# ТЗ и Мастер-Промпт для разработки конверсионного EdTech-лендинга (Версия 6)

## 1. Контекст и целеполагание проекта
* **Продукт:** «AI Sana» — интерактивная игровая образовательная платформа для обучения детей 1–4 классов (7–10 лет) основам искусственного интеллекта, алгоритмике, логике и цифровой гигиене.
* **Главный фокус лендинга (B2B):** Руководители частных и общеобразовательных школ, завучи начальных классов, учителя информатики и педагоги начальной школы, центры детского развития.
* **Вторичный фокус лендинга (B2C):** Родители учеников 1–4 классов, которым важно понимать безопасность платформы, снятие страхов («ИИ отупляет», экранное время) и возможность домашних занятий.
* **Ключевая цель страницы:** Сконвертировать администрацию школы или учителя в заявку на **бесплатный пилотный доступ на 1 класс (14 дней)** с предоставлением методического пакета и обучения педагога.
* **Модель лидогенерации:** Быстрый переход в один клик в WhatsApp / Telegram методиста-координатора с предзаполненным структурированным сообщением под выбранный контекст.

## 2. Архитектура и стек технологий
* **Стек фронтенда:** Чистый веб-стек (Vanilla HTML5 + Vanilla CSS3 + Vanilla JavaScript ES6+). Без сборщиков (Webpack/Vite/Parcel), запуск открытием файла в браузере или через статический локальный веб-сервер.
* **3D-сцена:** `Three.js` (подключение через официальный CDN, например `cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js`).
  * **Требование к 3D:** Полностью процедурный 3D-робот-маскот, собранный из геометрических примитивов (Sphere, Cylinder, RoundedBox/Cylinder, Torus) с Toon/PBR материалами (`MeshStandardMaterial` с мягким глянцем).
  * **Запрет внешних файлов:** Никаких внешних `.glb` / `.gltf` / `.obj` файлов. Сцена должна быть 100% автономной и не падать из-за CORS при локальном запуске по протоколу `file://`.
* **Иконки:** Векторные SVG-иконки (Lucide CDN или встроенные SVG-спрайты).
* **Локализация (i18n):** Архитектура словаря `i18n` вынесена в структуру JavaScript (`app.i18n`). Все текстовые ноды снабжены атрибутом `data-i18n="section.key"`. Базовый эталонный язык ТЗ и первой генерации — **Русский (RU)**, с готовностью архитектуры к переводу на Казахский (KZ) и Английский (EN).

### 3.2. Принципы анимации и взаимодействий
1. **Тактильный микроотклик:** Кнопки при нажатии слегка сжимаются (`transform: scale(0.98)`). При наведении на карточки — мягкий подъем на 4px с увеличением глубины тени (`transition: all 0.25s cubic-bezier(0.16, 1, 0.3, 1)`).
2. **Параллакс и взгляд робота:** 3D-робот плавно следит головой и взглядом за курсором мыши или тачем на экране с использованием коэффициента затухания `lerp(current, target, 0.08)`.
3. **Плавная прокрутка:** Нативная плавная прокрутка (`scroll-behavior: smooth`) с отступом шапки.

### Блок 9. Блок ответов на частые вопросы (FAQ Accordion)
* **«Нужна ли школе специальная компьютерная техника?»**
  * *Ответ:* Нет. Платформа работает прямо в браузере на любых компьютерах, моноблоках, планшетах и смарт-досках с доступом в интернет. Установка сторонних программ не требуется.
* **«Как подготовить учителей начальных классов, если у них нет IT-образования?»**
  * *Ответ:* Методика создана с расчетом на учителей без навыков программирования. В комплект входят подробные поурочные сценарии со словами учителя, а наш методист проводит 1-часовой живой онлайн-интенсив и всегда на связи.

  * *Ответ:* Серверы и хранилища строго соответствуют законодательству о защите персональных данных. Ученики могут регистрироваться под анонимными игровыми логинами (например, «Звездный Лис 24»), без указания фамилий и личных данных.
* **«Можно ли проводить уроки без интернета в кабинете?»**
  * *Ответ:* Для интерактивных генераций требуется базовое интернет-соединение, но все методические карты и рабочие листы для детей можно распечатать заранее.
* **«Как родители узнают о том, чем занимается ребенок?»**
  * *Ответ:* Учитель в один клик может распечатать или отправить в родительский чат красивую памятку о пройденном уроке и ссылку на домашний просмотр детского проекта.

### 5.2. Спецификация процедурного 3D-робота в `app.js` (Three.js)
```javascript
// Архитектура 3D-сцены:
// 1. Scene, PerspectiveCamera (fov: 45), WebGLRenderer (alpha: true, antialias: true).
// 2. Освещение: DirectionalLight с мягкими тенями + AmbientLight (0xffffff, 0.8) + легкий точечный Rim-light сзади.
// 3. Анатомия робота из примитивов:
//    - Тело: Rounded Cylinder или закругленный куб (MeshStandardMaterial, color: 0xffffff, roughness: 0.25).
//    - Голова: Закругленная сфера-капсула, вращающаяся по осям X/Y за курсором.
//    - Лицо-экран: Черный глянцевый дисплей с двумя светящимися бирюзовыми глазами (Dynamic Canvas2D Texture).
//    - Глаза: Моргают каждые 4 секунды, меняют форму на дуги-улыбки при кликах.
//    - Антенна: Тонкий цилиндр с сияющей сферой-лампочкой на конце (Emissive glow).
// 4. Аксессуары для переключения состояний:
//    - Режим "Художник": Процедурный берет (Torus + Sphere сплюснутая) фиолетового цвета.
//    - Режим "Учитель": Академическая четырехугольная шапочка магистра с золотой кисточкой.
//    - Режим "Геймер": Процедурный джойстик в руках робота.
// 5. Анимационный цикл: requestAnimationFrame с мягким покачиванием (floating/hover bobbing по синусоиде: y += Math.sin(time * 2) * 0.005).
```

### 5.3. Логика формирования ссылок WhatsApp и Telegram
```javascript
function openMessengerLead(role, targetAction, extraDetails = "") {
  const phone = "77001234567"; // Официальный номер методической службы
  const telegramBot = "aisana_edu_bot";
  
  let message = `Здравствуйте! Меня интересует платформа AI Sana.\n`;
  message += `Моя роль: ${role}\n`;
  message += `Цель: ${targetAction}\n`;
  if (extraDetails) message += `Детали: ${extraDetails}\n`;
  message += `Пожалуйста, свяжитесь со мной для предоставления материалов.`;
  
  const encoded = encodeURIComponent(message);
  return {
    whatsappUrl: `https://wa.me/${phone}?text=${encoded}`,
    telegramUrl: `https://t.me/${telegramBot}?start=${encodeURIComponent(targetAction)}`
  };
}
```

### 5.4. Требования к адаптивности (Responsive Breakpoints)
* **Desktop (1200px+):** Двухколоночный Hero (слева текст и оффер, справа 3D-сцена 500x500px), полноразмерный дашборд учителя, 3 колонки тарифов.
* **Tablet (768px – 1199px):** Уменьшение масштаба 3D-сцены до 380px, перенос акцентов под робота, скроллируемые табы поурочных планов.
* **Mobile (320px – 767px):** Одноколоночный вертикальный стек. 3D-робот масштабируется под ширину экрана (высота 300px), крупные сенсорные кнопки (высота не менее 48px), липкая плашка быстрой связи с методистом внизу экрана.

## 6. Критерии приемки и проверки качества (Definition of Done)
1. **Конверсионная ясность:** С первых 5 секунд нахождения на сайте директор или учитель понимает, что это готовое решение для начальной школы с методичками и поддержкой, а не просто абстрактный сайт про ИИ.
2. **Нулевая зависимость от внешних файлов 3D:** Three.js скрипт генерирует красивого робота без единого запроса к `.glb`/`.gltf`. Страница запускается локально без ошибок в консоли.
3. **Рабочий интерактив симулятора:** Учительский дашборд переключает классы, меняет данные в таблице, наглядно демонстрирует простоту контроля успеваемости.
4. **Рабочий калькулятор:** Ползунки классов и учеников моментально пересчитывают стоимость и формируют кастомное сообщение для отправки в мессенджер.
5. **Высокая производительность:** Первый экран отрисовывается моментально, FPS 3D-сцены стабильно держится на уровне 60 fps на десктопах и мобильных устройствах.
