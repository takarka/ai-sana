# AI Mektep — вторая версия лендинга

Самостоятельная альтернатива первой версии (в корне репозитория), построенная
по ТЗ (`../requrement`) — онлайн-платформа обучения школьников ИИ и
ИИ-инструментам. Чистый HTML/CSS/JS без сборки — откройте
`index.html` двойным кликом.

```
index.html   разметка, 16 секций и модалка
styles.css   токены, сетка, типографика, компоненты, адаптив
app.js       графики на инлайн-SVG и весь интерактив
i18n.js      словарь RU/KZ и переключение языка
```

Внешних зависимостей две: Google Fonts (Golos Text, Literata). Chart.js,
canvas-confetti и иконочные шрифты сознательно не подключены — графики и
пиктограммы нарисованы инлайновым SVG, поэтому страница работает офлайн.

## Концепция: «Шкала»

Продукт учит не «нажимать кнопки в нейросети», а понимать инструмент — и
превращает это понимание в измеримую траекторию. Поэтому страница сделана как
размеченная поверхность: сквозь всю страницу проходят вертикальные линии
сетки, и они совпадают с реальными колонками контента — с границей левой рейки
и с четвертями основной колонки. Данные наносятся на эту же систему координат.

Одна смелая вещь — герой: заголовок стоит на оси прогресса по курсу
`45 → 58 → 67 → 78 → 85` (цифры из ТЗ §11), которая один раз прочерчивается
при загрузке. Всё остальное держится тихо.

## Токены

| Роль | Значение |
|---|---|
| фон страницы | `--paper #ECEFE8` — холодный шалфейно-серый |
| панели | `--sheet #F8FAF5` |
| текст | `--ink #17201B`, вторичный `--ink-soft #5A665C` |
| линии | `--rule #C7CEC0`, слабые `--rule-soft #D8DDD2` |
| радиус | `--r 2px` — один на всё |
| тени | нет ни одной |

Акцентов как таковых нет — есть **шкала уровня освоения**, и она означает одно
и то же на всей странице: в бейджах, в таблице учителя, в распределении класса,
в линиях графиков.

| Уровень | Цвет |
|---|---|
| высокий | `--lvl-high #6B3FA0` |
| выше среднего | `--lvl-good #35688F` |
| средний | `--lvl-mid #D99A3C` |
| требует внимания | `--lvl-low #B8452E` |

Цвет нигде не единственный носитель смысла — рядом всегда подпись.

## Типографика

- **Golos Text** (500/600/800) — заголовки, интерфейс, кнопки, числа. Гротеск,
  спроектированный под кириллицу, с полным казахским набором (ә ғ қ ң ө ұ ү һ і).
- **Literata** (400/500) — весь пояснительный текст. Экранная антиква, сделанная
  для чтения: продукт объясняет, как устроен ИИ, и объяснение должно читаться,
  а не просматриваться.

Обычная пара «серифный дисплей + гротеск в тексте» здесь перевёрнута. Шаг
масштаба ≈1.25, длина строки ≤ 66 символов, `line-height` 1.7 для антиквы.

## Чем отличается от первой версии

| | v1 | v2 |
|---|---|---|
| тема | тёмная, slate `#070B14` | светлая «бумага» `#ECEFE8` |
| акцент | cobalt `#3B82F6` + emerald/amber/rose | четырёхступенчатая шкала уровня |
| шрифты | Plus Jakarta Sans + JetBrains Mono | Golos Text + Literata |
| поверхности | glassmorphism, радиусы 8–16px, тени, glow | плоские панели, радиус 2px, hairline, без теней |
| фон | радиальные градиентные «ауры» | структурная сетка колонок |
| графики | Chart.js в макете дашборда | инлайн-SVG на сетке страницы |
| композиция | центрированные заголовки, 680px | левая рейка + широкая колонка, всё по левому краю |
| иконки | Phosphor Icons (CDN) | шесть штриховых SVG в спрайте |

## Движение

Одно оркестрованное движение — прорисовка траектории в герое при загрузке.
Всё остальное движение отвечает на действие человека: открытие вопроса,
смена фильтра, проверка ответа. `prefers-reduced-motion: reduce` показывает
финальные состояния сразу.

## Доступность

Контраст текста ≥ 4.5:1, видимый `:focus-visible` (фиолетовая обводка),
аккордеон на `aria-expanded`, модалка с ловушкой фокуса и закрытием по Escape,
таблица кабинета учителя скроллится внутри своего контейнера. Горизонтального
скролла страницы нет на 360–1440px.

## Языки

RU и KZ переключаются в шапке и в подвале, выбор хранится в `localStorage`.
При смене языка перерисовываются графики, таблица учителя и список вопросов —
через событие `languageChanged`.
